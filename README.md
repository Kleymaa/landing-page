# Проект: Автосервис (Landing Page)

Лендинг для системы учета заказ-нарядов и клиентов автосервиса.

## Функционал
- Онлайн-запись на техническое обслуживание.
- Прозрачный расчет стоимости ремонта и расходных материалов.
